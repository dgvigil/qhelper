# Code of Conduct

We want Q Helper to be a welcoming project for everyone, including the
volunteer community it serves.

## Expected behavior

- Be respectful, patient, and constructive.
- Assume good faith; critique code and ideas, not people.
- Respect differing experience levels and viewpoints.

## Unacceptable behavior

- Harassment, insults, discrimination, or personal attacks.
- Publishing others' private information.
- Spam or deliberately disruptive behavior.

## Enforcement

The maintainer may remove comments, close issues or pull requests, or block
contributors who violate these expectations. Report concerns privately through
GitHub's "Report content" feature or by contacting the maintainer, Dave Vigil,
through his GitHub profile (<https://github.com/dgvigil>).

This policy is adapted in spirit from the Contributor Covenant,
<https://www.contributor-covenant.org/>.
